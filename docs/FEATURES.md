# Play Console features worth knowing

Each entry names the help article it comes from. The description is based on the article title. Read the article before relying on it.

| Feature | Source | What it is for |
|---|---|---|
| Play App Signing | app-signing | Google holds the app signing key; you upload with an upload key |
| Pre-launch report | pre-launch-report | Tests your uploaded build on Google's test devices and reports issues |
| Pre-review checks | pre-review-checks | Catches issues before a submission is reviewed |
| Test tracks (internal, closed, open) | test-tracks | Controlled testing before production |
| Play Integrity API | play-integrity | Signals about whether an app runs on a genuine, unmodified device |
| Anti-tamper protection | anti-tamper | Protection against modified copies of an app |
| Declare permissions | declare-permissions | Declarations for permissions that need them |
| Data safety form | data-safety | Declares data collection and sharing for the store listing |
| Developer verification | developer-verification-packages | Verifies the developer identity and registers package names |
| AI content declaration | ai-content-declaration | Declares AI-generated content in submitted assets |
| Technical quality | technical-quality | Vitals thresholds for stability and performance |
| Subscriptions | subscriptions | Subscription products, offers and cancellation requirements |
| In-app products (one-time) | help-center-index | One-time purchases; see the Help index for "Create an in-app product" |
| Refunds and orders | refunds-orders | Issuing full and partial refunds |
| Policy Insights in Android Studio | help-center-index | Policy checks from inside the IDE (see the Help index) |
| Store listing experiments | help-center-index | A/B tests on store listing assets (see the Help index) |

Items marked as from the Help index were found by crawling the index. They are not yet in `sources/sources.json` as their own sources.
