---
title: Third-party SDKs
sources: [sdk-policy, third-party-sdks]
last_reviewed: 2026-10-30
verified: checked against source text (SDK responsibility, data treatment, 90-day update rule)
---

- If you include an SDK, you are responsible for its code and practices complying with the Play policies, and it must not cause your app to break them.
- Treat data an SDK collects within your app as if you had collected it directly, and declare it in the Data safety form.
- Share user data collected through your app with third parties only as the SDK guidance allows.
- Use SDKs only from sources you trust and keep them updated.
- If an SDK version has critical issues, update to a newer version within 90 days of the release that fixes them. After 90 days, you can no longer release app versions that use the affected SDK version.
- Review the SDK guidance before adding an advertising, analytics or authentication SDK.
