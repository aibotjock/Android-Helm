title: Target API level
sources: [target-api, policy-deadlines]
last_reviewed: 2026-10-30
verified: checked against source text
---

- From 31 August 2026, new apps and updates must target Android 16 (API 36) or higher, with exceptions for Wear OS, Android Automotive, Android TV and Android XR.
- Existing apps must target API 35 or higher to stay available to new users on newer Android versions.
- An extension to 1 November 2026 was available on request for updates that needed more time.
- The target is the targetSdkVersion declared in the manifest. Check it on every release.
- Check the target-api page for each new minimum; do not assume the pattern repeats.
